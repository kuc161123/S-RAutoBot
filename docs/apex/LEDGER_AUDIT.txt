Implemented contracts (limited to assigned files)
- ReferenceReader(session, store, credentials_json='', file_ids=tuple()) uses
  explicit file IDs only and read-only Drive/Sheets scopes. No folder discovery,
  shortcut following, external writes, credential files or ambient credentials.
  Native Docs export to plain text. Sheets reads are restricted to Settings
  A1:E180, Counts A1:K250, Levels A1:Q100 and CCR A1:K50 plus bounded metadata.
- Native Drive version and modified time are checked before/after each read;
  responses have byte/time limits and bounded transient retries. Snapshots
  include content/provenance hashes and asof. Every observed version is retained
  in the NEW store's event audit. Failed refreshes retain the prior snapshot
  without renewing asof or calling it current. Revision regressions fail closed.
- Source text is untrusted evidence, with policy_authority=False. It does not
  change settings, execute instructions or automatically become live policy.
  Source changes emit a review notice through the new store's Telegram outbox.
- Optional load_context validates a public HTTPS JSON feed, DNS/IP safety and
  pinned TLS requests; redirects are refused. Required timestamps, bounded
  multipliers, risk state, scoped blackout and dated public sources are checked.
  Missing/invalid data returns fresh=False, live_blocked=True, no invented
  neutral regime. Provider assertions are not independent fact verification.
